Solid to SCAD

STL files in, one parametric .scad out, ready for MakerWorld's Parametric Model Maker.

1. Default model

Export the model at its default values. Each STL file becomes one part (a file can hold several bodies).

    2. Values

    For each value people should be able to change, export the model again with only that value changed and add those files here. The app works out what the value moves by comparing the two exports.

    3. Export

    Add one or more STL files to start.
